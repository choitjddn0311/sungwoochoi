## 소개

국민대학교 인공지능학부 26학번입니다. 웹 개발을 주로 해 왔고, AI 분야 중에서는 컴퓨터 비전에 관심이 있습니다. 사진 촬영, 색보정, 영상 편집도 좋아합니다.

이 사이트는 개발과 사진·영상 작업을 한곳에 모은 공간입니다. 디자인부터 구현까지 직접 만들고 있습니다.

## 디자인

필름을 고르는 밀착 인화지(Contact Sheet)에서 출발한 흑백 에디토리얼 디자인입니다.

- 포인트 컬러 없이 크기와 위치, 흑백 반전만으로 위계를 만들었습니다.
- 글과 프로젝트, 사진을 같은 프레임으로 다루고, 숫자는 실제 개수만 표시합니다.
- 큰 글자와 작은 정보성 글자의 대비로 화면을 구성했습니다.
- 첫 방문은 다크 모드로 보여 주고, 라이트 모드와 한국어·영어 전환을 지원합니다.

## 만든 방법

| 구분 | 사용 기술 |
|---|---|
| 프레임워크 | Next.js 16 (App Router), React 19, TypeScript |
| 스타일 | Tailwind CSS v4 |
| 글 | MDX, rehype-pretty-code |
| 다국어와 테마 | next-intl, next-themes |
| 댓글 | utterances |
| 배포 | Vercel |

직접 신경 쓴 부분은 다음과 같습니다.

- **프레임 띠:** 라이브러리 없이 구현한 가로 슬라이드입니다. 버튼, 방향키, 터치로 조작할 수 있습니다.
- **영상:** 썸네일을 먼저 보여 주고, 누를 때 플레이어를 불러와 첫 로딩을 가볍게 했습니다.
- **접근성:** 글자 대비, 키보드 조작, 동작 줄이기 설정을 고려했습니다.
- **검색 노출:** 메타데이터, 사이트맵, 페이지별 공유 이미지를 넣었습니다.
